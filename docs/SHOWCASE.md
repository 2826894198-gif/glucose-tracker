# 家人血糖本 · 面向长辈的个人健康记录 · 项目展示

## 一句话介绍

让长辈容易记，让家人看得清：把血糖记录、趋势回看和弱网下的数据保护做成一个完整工具。

## 项目价值

围绕长辈的手动记录、照片核对和趋势回看构建原生微信产品，结合账号隔离、离线队列、云端确认和独立 OCR 容器，兼顾易用性与工程可靠性。

## 最值得展示的能力

- 手动输入、拍照/相册后核对、历史详情与近期分析
- 个人范围、字体设置、删除恢复与独立隐私入口
- 可信微信身份隔离及按账号分区缓存

## 说明范围

当前阶段：工程 0.1.0 已上传开发版本，专用云环境与管理员身份真实云读写已打通；尚未设体验版、添加父母及双账号真机验收。。

- 97 项工程测试与 9 项容器测试为已记录结果，本轮未重跑。
- 线上照片 OCR 尚未部署云镜像或配置识别地址；真实照片识别质量未验收。
- 父母双账号、换机恢复、弱网、键盘和相机权限仍需真机验收。
- 只做记录和描述性回看，不提供医疗诊断或准确率承诺。
- 不是端到端加密；上游 SDK 仍有未修补审计项；不承诺永久免费。
- 根目录 README 描述早期 PWA，当前微信产品以 wechat/README.md 为准。

对外演示使用合成数据。源码、演示、历史验收记录与实时线上状态分别说明；任何效果数字都需要可追溯的测量记录。
