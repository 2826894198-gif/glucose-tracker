# 公开工程状态

原项目版本 0.1.0，曾上传开发版本并验证管理员身份的基本云端读写；尚未完成父母双账号真机验收或公开发布。私有云标识、个人数据、照片、上传回执及实际云端读回输出不包含在本仓库。

公开示例保留原生页面、独立共享模型、服务端可信身份隔离、离线队列、幂等同步、删除恢复、冲突处理、OCR 桥接与容器实现。默认 AppID 和云环境使用占位值，不自动连接云端。

本次公开整理在不联网、不登录、不上传的条件下通过原生构建、wcc/WXSS 编译及 97 项离线测试。原演示照片已移除，使用无测值的通用图标；OCR 单元测试采用该合成图片和伪造响应。

可选 Linux OCR 真实推理测试需要使用者提供自己制作的合成仪表图，并通过 `OCR_SYNTHETIC_FIXTURE` 指定。仓库不提供私人仪表照片，也不将单元测试称为真实识别准确率或生产 OCR 验收。

真实双账号、换机取回、弱网补传、冲突、字体/键盘与相机权限需要在自己的环境和真机完成。上游 SDK 审计项仍须按 [云端安全](cloud-security.md) 的限制评估，不宣称风险清零、端到端加密或永久免费。
